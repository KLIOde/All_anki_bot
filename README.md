Это телеграмм бот который помогает выучить английский язык:
1. Конвертирование файлов из формата .txt и .csv в формат .apkg.
2. Открытие файлов .apkg.
3. Извлечение из файла рандомного слова и генерация на его основе характерного текста с помощью разных LLM моделей.
4. Возможность поддерживать диалог.
